2. 用现代浏览器（Chrome, Firefox, Safari, Edge）打开 `index.html` 即可。
3. 无需安装任何依赖或后端服务。

### 初始设置
- 输入你的名字、出生日期、期望寿命（岁），点击“开启人生之旅”。
- 之后即可浏览人生网格并添加日程。

### 基本操作指南
- **添加日程**：点击某一天 → 侧边栏出现 → 在24小时时间轴上点击任意小时（或点击顶部“+新建日程”）→ 填写标题、类型、时间等 → 保存。
- **编辑日程**：在侧边栏日程块上右键 → 选择“编辑”；或者在主视图日期格内直接点击日程小方块。
- **删除日程**：右键单击日程 → 删除；重复日程可选择“仅删除此日程”或“删除所有日程”。
- **缩放/平移**：鼠标滚轮 / 双指捏合；拖拽画布背景。
- **切换视图**：底部控制栏提供“全局”、“今年”、“本月”、“今天”快速定位。

## 技术栈

- **原生 HTML5 / CSS3 / JavaScript (ES6)**：无任何第三方框架，轻量且可维护。
- **Canvas 2D**：渲染动态网格、缩放平移、日程小圆点等。
- **localStorage**：持久化用户数据、语言偏好、侧边栏分割比例。
- **Google Fonts**：使用 `Playpen Sans` 和 `Zen Maru Gothic` 字体，提升视觉体验。
- **响应式设计**：通过媒体查询适配手机、平板、桌面。

## 注意事项

- **数据安全**：由于数据仅存储在浏览器本地，清除浏览器缓存或更换设备会导致数据丢失。建议定期使用“导出日程”功能备份。
- **跨设备同步**：不支持自动同步，您需要手动导出并在另一设备导入。
- **移动端体验**：侧边栏可拖拽宽度（桌面）或自适应全宽（移动），待办列表与时间线区域可通过中间分割条调整上下比例。
- **性能**：渲染完整生命周期（最长120年）时，Canvas 采用视口裁剪优化，仅绘制可见区域，性能良好。
