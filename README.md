# 人生日历 · Life Calendar Grid

> 将生命可视化为可交互的网格日历，支持日程管理、待办清单、多语言、数据导入导出，帮助规划与记录每一日。

## 项目简介

“人生日历”是一个纯前端、无需后端服务的交互式生命规划工具。用户输入姓名、出生日期和预期寿命后，系统会生成以年-月-日网格布局的“人生视图”，每个方格代表一天。通过缩放和平移，可以宏观浏览整个生命周期，或聚焦到某一天添加日程、查看时间线。

- **核心理念**：将有限的生命可视化，提醒珍惜时间，同时提供实用的日程与任务管理。
- **数据隐私**：所有数据（日程、待办状态）仅保存在浏览器的 `localStorage` 中，不会上传至任何服务器。
- **多端适配**：同时支持桌面端（鼠标滚轮缩放、拖拽平移）和移动端（手势缩放、侧滑菜单）。

## 主要功能

### 1. 人生网格视图
- 以年-月-日三层嵌套网格展示从出生到预期寿命结束的每一天。
- **缩放**：滚动鼠标滚轮（桌面）或双指捏合（移动）可逐步深入月视图、日视图。
- **平移**：拖拽画布可浏览不同年份/月份。
- **视觉区分**：
  - 淡灰色背景 = 已过去的日子
  - 暖白色背景 = 未来的日子
  - 红色边框高亮 = 今日
  - 年份/月份内若有日程，会有小圆点提示。

### 2. 日程管理
- **添加/编辑/删除日程**：点击任意日期格子打开侧边栏，点击时间线区域或“新建日程”按钮即可添加。
- **日程类型**：工作、个人、健康、学习、重要事项、纪念日、生日、其他，每种类型有独立颜色。
- **时间设置**：支持全天日程或指定起止时间（精确到分钟）。
- **重复日程**：支持每日、每周、每月、每年重复，并可单独删除某一次重复实例（例外日期）。
- **拖拽调整**：在侧边栏的时间线视图中，直接拖拽日程块可移动时间；拖拽上下边缘可调整时长。

### 3. 侧边栏（当日视图）
- 显示选定日期的 **24小时时间轴**，所有非全天日程按时间位置排列。
- 顶部区域显示 **全天日程**。
- 支持右键快捷编辑/删除日程，左键点击日程查看详情。

### 4. 待办清单（To-Do List）
- 位于侧边栏下半部分，列出当天所有日程，并可通过复选框标记“已完成”。
- 待办完成状态独立存储，与日程本身分开，便于跟踪每日任务完成情况。
- 已完成项自动移到底部，未完成项按时间排序。

### 5. 多语言支持
- 内置 **14 种语言**：英语、简体中文、繁体中文、西班牙语、日语、韩语、法语、德语、意大利语、葡萄牙语、俄语、阿拉伯语、印地语、泰语。
- 桌面端右上角下拉菜单切换；移动端左上角地球图标切换。

### 6. 数据备份与恢复
- **导出日程**：将所有数据（用户信息、日程、待办状态）导出为 `.json` 文件，文件名格式为 `用户名_lifetime_grid_backup_时间戳.json`。
- **导入日程**：选择之前导出的 `.json` 文件，导入前会弹出警告（覆盖当前所有数据），确认后刷新页面生效。

### 7. 生命周期调整保护
- 若用户尝试将预期寿命减少到低于已有事件覆盖的年份，系统会弹出警告，提示部分年份的日程将不再显示（但不会丢失），防止误操作导致日程不可见。

### 8. 快捷键
- `+` / `=`：放大
- `-`：缩小

## 使用方法

### 运行方式
1. 下载所有源代码文件，保持如下目录结构：
   project/
├─ index.html
├─ style.css
└─ js/
├─ state.js
├─ lang.js
├─ render.js
├─ interaction.js
├─ sidebar.js
├─ modal.js
└─ app.js
2. 用现代浏览器（Chrome, Firefox, Safari, Edge）打开 `index.html` 即可。
3. 无需安装任何依赖或后端服务。

### 初始设置
- 输入你的名字、出生日期、期望寿命（岁），点击“开启人生之旅”。
- 之后即可浏览人生网格并添加日程。

### 基本操作指南
- **添加日程**：点击某一天 → 侧边栏出现 → 在24小时时间轴上点击任意小时（或点击顶部“+新建日程”）→ 填写标题、类型、时间等 → 保存。
- **编辑日程**：在侧边栏日程块上右键 → 选择“编辑”；或者在主视图日期格内直接点击日程小方块。
- **删除日程**：右键单击日程 → 删除；重复日程可选择“仅删除此日程”或“删除所有日程”。
- **缩放/平移**：鼠标滚轮 / 双指捏合；拖拽画布背景。
- **切换视图**：底部控制栏提供“全局”、“今年”、“本月”、“今天”快速定位。

## 技术栈

- **原生 HTML5 / CSS3 / JavaScript (ES6)**：无任何第三方框架，轻量且可维护。
- **Canvas 2D**：渲染动态网格、缩放平移、日程小圆点等。
- **localStorage**：持久化用户数据、语言偏好、侧边栏分割比例。
- **Google Fonts**：使用 `Playpen Sans` 和 `Zen Maru Gothic` 字体，提升视觉体验。
- **响应式设计**：通过媒体查询适配手机、平板、桌面。

## 注意事项

- **数据安全**：由于数据仅存储在浏览器本地，清除浏览器缓存或更换设备会导致数据丢失。建议定期使用“导出日程”功能备份。
- **跨设备同步**：不支持自动同步，您需要手动导出并在另一设备导入。
- **移动端体验**：侧边栏可拖拽宽度（桌面）或自适应全宽（移动），待办列表与时间线区域可通过中间分割条调整上下比例。
- **性能**：渲染完整生命周期（最长120年）时，Canvas 采用视口裁剪优化，仅绘制可见区域，性能良好。
